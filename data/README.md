# Fruit_v3 – מערך הנתונים

מערך תמונות לסיווג 5 קטגוריות: **Apple, Avocado, Banana, Eggplant, Tomato**.
זה מערך האימון והבדיקה של גרסה v3 של Fruit Vision. התיקייה `Fruit_v3/` מכילה את כל התמונות, כך שאפשר לשחזר את האימון.

```
Fruit_v3/
├── train/<Fruit>/*.jpg      תמונות אימון
├── test/<Fruit>/*.jpg       תמונות בדיקה (לא משתתפות באימון)
├── manifest.csv             לכל תמונה: split, class, file, origin, source
└── web_sources_licenses.csv כותרת, קישור, רישיון ויוצר לכל תמונת אינטרנט
```

## שלושה מקורות

| `origin` ב-manifest | תיאור | קידומת שם קובץ |
|---|---|---|
| `fruits360` | [Fruits-360](https://www.kaggle.com/datasets/moltean/fruits) (100×100). פרי על מנוע מסתובב מול דף לבן, הרבה זנים | `f360_` |
| `phone_photo` | תמונות טלפון אמיתיות מ-Fruits-360 (תיקיית `multi`): ארגזים, עצים ושווקים. נחתכו ל-4 קטעים ריבועיים (224×224) | `real_` |
| `web_commons` | תמונות מ-[Wikimedia Commons](https://commons.wikimedia.org) ברישיון פתוח. נבחרו ידנית, ואז נחתך כל פרי בודד (224×224) | `web_` |

### איך נבנו תמונות האינטרנט

1. נאספו כ-330 מועמדות (5 חיפושים לכל פרי), רק ברישיונות CC0 / CC-BY / CC-BY-SA / Public Domain.
2. עברתי עליהן ידנית ובחרתי 113 תמונות של פרי שלם. לא נבחרו חצויים, מנות אוכל, איורים וציפורים שאוכלות פירות.
3. כל תמונה הועברה ל-workflow של סגמנטציה ב-Roboflow, שמחזיר מיקום לכל פרי. נשמרו רק חיתוכים שזוהו כאותו פרי שבתיקייה (עד 10 מכל תמונה).
4. כל חיתוך נחתך לריבוע 224×224, עם ריפוד אפור כדי שהפרי לא יימתח.

הסקריפטים ב-[`../tools/`](../tools) (`fetch_commons.py`, `web_crops.py`, `build_dataset.py`). הנתיבים בהם הם של המחשב שבו נבנה המערך ויש לשנות אותם.

## מניעת דליפה בין אימון לבדיקה

תמונות רצופות של אותו פרי כמעט זהות. אם הן מתפצלות בין אימון לבדיקה, הדיוק המדווח מנופח. ב-v1 זה כנראה קרה: דיוק של 100% בוולידציה כבר באפוק 2.

- **Fruits-360:** לבדיקה נבחרו **זנים שלמים שלא הופיעו באימון**:
  - Apple: `12`, `19`, `5`, `Braeburn 1`, `Granny Smith 1`, `Red Delicious 1`
  - Avocado: `Black 1`
  - Banana: `4`
  - Tomato: `11`, `7`, `Cherry Orange 1`, `Maroon 1`
  - Eggplant יש רק שני זנים, ולכן חולק לפי בלוקים של תמונות (עם רווח ביניהם). הבדיקה בחציל אופטימית יותר.
- **תמונות טלפון ואינטרנט:** החלוקה לפי **התמונה המקורית**, לפני החיתוך. חיתוכים מאותה תמונה לא מופיעים גם באימון וגם בבדיקה (נבדק: 0 חפיפה).
- הדגימה מכל זן היא במרווחים שווים בין התמונות (זוויות שונות), ולא תמונות רצופות.

## מגבלות

- רוב האימון (כ-86%) עדיין תמונות מעבדה על רקע לבן.
- **אבוקדו** כמעט ללא תמונות טלפון אמיתיות (רק חיתוכי אינטרנט).
- יש מעט תמונות אמיתיות של בננה (118 באימון) וחציל (91).
- ב-Granny Smith (תפוח ירוק) יש רק תמונות בדיקה. באימון לא הופיע הזן הזה מ-Fruits-360, אבל יש תפוחים ירוקים בתמונות האינטרנט.
- חלק מחיתוכי התפוחים מעצים מראים בעיקר עלים.
